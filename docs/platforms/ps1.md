# PS1 - Sony Playstation (PSX)

## Serial

PS1 games have unique codes that identify game region:

SCPS, SLPS 	Japanese games.
SCUS, SLUS 	American games.
SCES, SLES 	European games.
SCKA, SLKA 	South Korean games. 

(Source: https://consolemods.org/wiki/AV:Sony_Model_Prefixes#PlayStation_and_PlayStation_2)
