# gba - Nintendo Game Boy Advance

## Serial

A GBA game has a serial made this way:

AGB-{GAME SERIAL}-{REGION}

## Data sources

### No-Intro set - DAT-O-MATIC

[Link](https://datomatic.no-intro.org/index.php?page=download&s=23)

Downloadable .xml/DB. Doesn't seems to have an API.

Has:

- Serial
- Gamename
- Parent-Clone relationship
- Hashes (CRC32, MD5, SHA1)
