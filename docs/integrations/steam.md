# Steam

## Standard install directory

```
/home/deck/.local/share/Steam
```

## Screenshot folder

```
<steam-install-directory>/userdata/<steam-user-id>/760/remote/<steam-game-code>/screenshots
```

Each folder inside `remote` is composed by the steam APPID code

If the game is a "non-steam game", a binding is contained within "screenshots.vdf" inside "760"
