# Project Orbit 🚀

A framework for collecting and organizing games (both retrogaming and modern), designed to be self-contained, multi-paradigm, and fast.

## 🛠 Development

### Prerequisites
- **Bun**: The primary runtime.
  - *Install (Linux/macOS):* `curl -fsSL https://bun.sh/install | bash`
  - *Install (Windows):* `powershell -c "irm bun.sh/install.ps1 | iex"`

### Project Setup
1. Clone the repository.
2. Install dependencies:
   ```bash
   bun install
   ```

### Useful Commands
- **Run the CLI:**
   ```bash
   bun orbit
   ```
